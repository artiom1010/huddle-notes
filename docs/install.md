# Как поставить Call Recaps себе

Call Recaps сам делает заметки и расшифровку звонка. Ты записываешь звонок в OBS, программа
замечает новую запись, расшифровывает её на твоём компьютере и присылает в твой канал Slack
сообщение с одним файлом: подробные заметки по темам и полная расшифровка со временем.
Заметки всегда на русском, расшифровка — на языке звонка.

**Установка из этого архива — только для Windows.**

## Что понадобится

- Компьютер с Windows 10 или 11, на котором ты записываешь звонки. Свободного места — несколько
  гигабайт: одни модели для расшифровки занимают около 1,6 ГБ.
- Своя платная подписка Claude. Заметки пишутся под твоим аккаунтом и расходуют его лимит.
- Приложение Claude для Windows: во вкладке Code Claude всё установит сам.
- OBS Studio — им записываются звонки.
- Архив «Call Recaps <дата>.zip» — он лежит рядом с этим гайдом.
- Свой канал в Slack и токен бота — см. шаг 1.

## 1. Подготовь Slack

**Канал — только свой.** Не используй `#call-recaps`: в нём уже работает другая установка.
Программа читает ответы под сообщениями своего бота о звонках в канале, чьи бы они ни были.
Если две установки с одним ботом пишут в один канал, каждая запишет себе чужие ответы как
пожелания, и обе ответят в треде. Канал может быть открытым или закрытым. Заметки и
расшифровки увидят все участники канала, а в открытый канал может зайти любой из рабочего
пространства Slack.

Бот — готовый или свой.

**Вариант А: готовый бот `@ai-recap` (проще)**
1. Создай свой канал в Slack.
2. Пригласи в него бота: напиши в канале `/invite @ai-recap`.
3. Токен бота попроси у Артёма Сары лично. Никому его не пересылай и не пиши в чат с Claude.

Токен у всех, кто выбрал этот вариант, один и тот же. У кого он есть, тот может читать
каналы, где есть бот `@ai-recap`, и писать в них от имени бота. Если звонки не для чужих
глаз, сделай своего бота.

**Вариант Б: свой бот**
1. Открой https://api.slack.com/apps → Create New App → From scratch. Задай имя и выбери
   рабочее пространство.
2. OAuth & Permissions → Bot Token Scopes: добавь `chat:write`, `files:write`,
   `channels:history`, `groups:history`, `users:read`.
3. Нажми Install to Workspace. Если в вашем Slack приложения одобряет администратор, бот
   заработает после его одобрения.
4. Скопируй Bot User OAuth Token (начинается с `xoxb-`).
5. Создай свой канал и пригласи в него бота: `/invite @<имя бота>`.

**Ещё понадобятся два ID.** Это не секрет, их можно написать Claude в чате.
- **ID канала:** нажми на название канала вверху, ID — внизу открывшегося окна («Channel ID»,
  вида `C0123ABC`).
- **Твой ID в Slack:** свой профиль → «⋮» → «Copy member ID» (вида `U0123ABC`). По нему бот
  отмечает тебя в сообщении о каждом звонке. Без него сообщения придут без отметки.

## 2. Распакуй архив

Скачай архив и распакуй в удобное место, например в `D:\Call Recaps`. Папка программы — та,
в которой лежит файл `CLAUDE.md` и папки «Записи» и «Результаты». Windows при распаковке
часто кладёт её ещё в одну папку с похожим именем — это нормально.

## 3. Попроси Claude установить

1. Открой приложение Claude → вкладка Code → выбери папку программы (ту, где `CLAUDE.md`).
2. Напиши: «Установи всё по инструкции из CLAUDE.md».
3. Claude сам поставит нужные инструменты, Whisper (расшифровка), программу, модели и Claude
   Code для терминала — команду `claude`, через которую пишутся заметки. Скачивание занимает
   время.
4. **Вход в `claude`** сделаешь сам: выполни в PowerShell команду входа, которую даст Claude,
   и войди в браузере своим аккаунтом Claude с подпиской.
5. Claude спросит и впишет сам:
   - ID твоего канала — без своего канала дальше не пойти;
   - твой ID в Slack;
   - часовой пояс, если ты не в поясе Кишинёва: по нему пишется время звонка;
   - словарь. В архиве словарь команды Zinrai: проекты, имена и термины, чтобы Whisper их
     правильно расслышал. Если ты из другой команды, Claude поможет составить свой.
6. **Токен Slack** — последним и сам: открой в Блокноте файл `.env` в папке программы, впиши
   токен в ту же строку сразу после `SLACK_BOT_TOKEN=` (новую строку не добавляй) и сохрани.
   В чат токен не пиши. Claude проверит, что он вписан, не показывая его.
7. Claude включит автозапуск: программа работает в фоне после каждого входа в Windows. Он
   покажет пробное уведомление «Проверка уведомлений» — скажи ему, всплыло ли оно в углу
   экрана.
8. OBS: Настройки → Вывод → Путь записи → папка «Записи» в папке программы. Формат mkv или
   mp4. Источник — «Захват окна» на окно звонка, плюс звук рабочего стола и микрофон. Для
   заметок программа берёт из записи только звук. Если OBS сам перепаковывает записи в MP4
   (расширенные настройки OBS, раздел про запись), выключи это: иначе одна запись придёт
   дважды.

Claude может попросить сделать руками что-то ещё, например перезапустить приложение Claude
или включить уведомления Windows. Он объяснит как.

## 4. Проверь

Запиши короткий звонок на 5–10 минут. Примерно через минуту после остановки записи в углу
экрана всплывёт «Взял в работу» с именем файла. Потом в твоём канале появится сообщение от
бота: отметка тебя, название звонка, имя записи и файл. Тот же файл будет в папке
«Результаты».

## Как пользоваться

- Перед звонком нажми «Начать запись» в OBS, после — «Остановить запись». Остальное программа
  сделает сама, пока компьютер включён и ты вошёл в Windows.
- **Не ставь запись на паузу:** паузу дольше полуминуты программа может принять за конец
  записи, и заметки будут только по части звонка до паузы. Если так вышло, попроси Claude
  в папке программы пересчитать этот звонок целиком.
- **Не понравились заметки?** Ответь в треде под сообщением бота, что не так: «пиши короче»,
  «задачи с датами». Примерно раз в 5 минут программа читает ответы, бот отвечает «Записал»,
  и со следующего звонка Claude это учитывает. Пожеланием становится любой ответ в треде,
  даже «спасибо». Читаются треды за последние 14 дней. На 👎 без слов бот сам спросит, что
  не так.
- **Вопросы по звонкам** задавай Claude в папке программы: «что поручили Жене на планёрке?»,
  «где говорили про iOS?».
- **Словарь** поправит Claude в папке программы: «добавь в словарь <название проекта>».
- **«Заметки не получились», а в причине сказано про вход** (например, `Login expired`): вход
  в `claude` истёк. Попроси Claude помочь войти снова. Программа просит заметки заново раз в
  30 минут, около 5,5 часа: если войти за это время, они придут сами.
- **Место на диске.** Записи и рабочие файлы программа не удаляет. Старые записи из
  «Записей» можно удалять самому, когда заметки по ним уже пришли.

## Обновления

Новая версия приходит архивом «Обновление Call Recaps <дата>». Распакуй его и напиши Claude
в папке программы: «Обнови программу из папки <куда распаковал>». Настройки, токен, записи и
результаты обновление не трогает.

## Что куда уходит

- Видео и звук остаются на твоём компьютере: расшифровку делает Whisper у тебя.
- В Claude уходит только текст: расшифровка, словарь и пожелания к заметкам.
- В Slack уходят сообщения о звонках и ошибках, файл с заметками и расшифровкой и ответы бота
  в тредах.
- Кто какую реплику сказал, программа не определяет: лица и голоса не используются.
- Токен лежит в `.env` на твоём компьютере. Токен готового бота есть и у других его
  пользователей.
